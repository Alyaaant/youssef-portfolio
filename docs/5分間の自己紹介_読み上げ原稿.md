# 5分間の自己紹介（合計約5分）

## 1. 自己紹介（45秒）
はじめまして、エルノビ ユッセフと申します。日本で育ち、エジプトにルーツがあります。日本語、アラビア語、英語を使います。子どものころからゲームが好きで、今では技術を使って自分でもアプリを作っています。今日は、私がどうやってエンジニアになったのか、そして今どんな開発をしているのかをご紹介します。

## 2. これまでの道（70秒）
高校卒業後、パーソルマーケティングでauの携帯販売を担当し、九州各地の家電量販店を巡っていました。お客様の要望を聞いて分かりやすく説明する力を学びました。もともとゲームが好きで「これ、どうやって作られているんだろう」と思っていたことがプログラミングを始めるきっかけでした。2023年にIT専門学校へ入学し、学校のITサポートも並行して経験しました。

## 3. 現職と個人開発（65秒）
2025年から株式会社システムアイに入社し、4名チームのリーダーとして社内Webアプリ開発を経験しました。現在はプロ野球6球団の公式サイト関連システムの運用・改修・テストを担当しています。個人開発ではSkolivioとNOOR JAPANを開発し、画面からAPI、DBまで一人で考えて形にしています。

## 4. NILE QUEST（60秒）
今回作ったのはエジプトから日本まで旅するクイズWebゲームです。5か国15問で、ログイン、スコア保存、外部天気APIを備えています。Node.jsで正誤判定を行い、SQLiteに記録しています。QRコードから実際にプレイできます。技術や設計については続くアプリ発表で詳しく説明します。

## 5. 大切にしていること（60秒）
ユーザーの目的を理解してから作り、最後まで動くか確かめることを大切にしています。AIは支援ツールとして使いますが、要件やセキュリティ、動作結果を自分で確認しています。今後はバックエンドを含めた技術力を高め、使われ続けるサービスを作れるエンジニアを目指しています。本日はよろしくお願いいたします。
