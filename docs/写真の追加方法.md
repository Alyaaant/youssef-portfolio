# 写真の追加方法

写真はまだ公開していません。自分で選んだ写真を後で追加する想定です。

1. ファーストビュー（顔写真）: `assets/profile.jpg` というファイル名で追加。
2. 写真ギャラリーは `assets/photos/` の下へ `sales.jpg`, `study.jpg`, `work.jpg`, `life.jpg` の4枚を追加。
3. `index.html` 中の `assets/photos/sales-placeholder.svg` などの4つのパスを `.jpg` に変更。
4. GitHubの `portfolio-site` ブランチに反映し、Railwayの専用ポートフォリオサービスを再デプロイ。

写真は圧縮して1枚あたり300KB前後を目安。公開してよい写真・同意のある写真だけを使用してください。
